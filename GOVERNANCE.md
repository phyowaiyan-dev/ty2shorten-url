# Governance

Ty2Shorten URL currently uses a simple maintainer-led governance model.

## Maintainer Responsibilities

- Review pull requests.
- Triage issues.
- Protect the project security posture.
- Keep documentation aligned with implementation.
- Decide release timing.

## Decision Making

Routine changes may be accepted through pull-request review. Larger architecture, security, or compatibility changes should be discussed in an issue before implementation.

## Releases

Maintainers decide when a tag is ready. Release authority may be expanded as additional maintainers join.

## Security Decisions

Security fixes may be developed privately when needed. Public disclosure should follow [SECURITY.md](SECURITY.md).

## Future Maintainers

Additional maintainers may be added after sustained, trusted contributions.
