# Support

Use GitHub Issues for reproducible bugs and focused feature requests.

Use GitHub Discussions when enabled for questions, deployment help, and broader ideas.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and should not be opened as public issues.

## Helpful Diagnostic Details

- Project version or commit.
- Operating system and architecture.
- Go version.
- Deployment method.
- Relevant configuration with secrets removed.
- Logs with passwords, cookies, and tokens removed.
- Exact reproduction steps.

Private consulting, custom deployment, and emergency support are not guaranteed by this open-source repository.
