# Security Policy

## Supported Versions

Ty2Shorten URL is currently alpha software. Security fixes are expected to target the current `main` branch until tagged releases are established.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Tagged releases | Not yet established |

## Reporting Vulnerabilities

Do not report vulnerabilities through public issues.

When GitHub private vulnerability reporting is enabled for the repository, use it. If it is not enabled, contact the maintainers through the least-public channel available in the repository metadata.

## What To Include

- Affected version or commit.
- Deployment environment.
- Reproduction steps.
- Impact assessment.
- Relevant logs with secrets removed.
- Whether the issue is already public.

## Secret Removal

Remove passwords, session cookies, CSRF tokens, API keys, database contents, IP addresses if sensitive, and private URLs before sharing logs.

## Disclosure

Please allow maintainers reasonable time to investigate and release a fix before public disclosure.

## Security Update Process

Security fixes should include tests where practical, documentation updates when behavior changes, and release notes once tagged releases exist.
