# Social Sharing

Open Graph and Twitter/X metadata are generated by `SEOService`.

Configured image fields:

- Open Graph default image
- Twitter/X default image
- Default social-share image from branding settings

Resolution order for the public landing page:

1. Open Graph image
2. Twitter/X image
3. Branding default social-share image

Relative `/media/...` values are converted to absolute URLs using the configured canonical/public base URL. Recommended social image dimensions are 1200 x 630 pixels, but the app does not currently enforce exact dimensions.

Known limit: the admin preview is basic through the SEO/branding forms; a richer visual card preview remains future work.
