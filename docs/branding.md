# Branding

Branding settings are edited at `/admin/settings/branding`.

Supported fields:

- Site tagline
- Logo
- Optional dark logo
- Favicon
- Apple touch icon
- Default social-share image

Each media field can be set by URL or by uploading an image. Uploads are stored outside embedded assets and served through `/media/:name`.

The public landing page renders the configured logo. The favicon, Apple touch icon, social image, and organization logo are used by the SEO metadata layer where configured.
