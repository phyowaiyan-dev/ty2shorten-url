# Media Uploads

Uploaded branding files are stored in `MEDIA_STORAGE_PATH`, defaulting to:

```text
./storage/media
```

Suggested production path:

```text
/var/lib/ty2shorten/media
```

Security controls:

- Files are stored outside embedded static assets.
- Public access goes through `/media/:name`.
- Filenames are random and generated by the server.
- Path traversal and nested paths are rejected.
- MIME type is detected from file contents.
- SVG is not accepted.
- Uploaded files are written with non-executable permissions.

Accepted MIME types:

- PNG
- JPEG
- WebP
- ICO

Size limits:

- Logo and dark logo: 2 MB
- Favicon and Apple touch icon: 512 KB
- Social-share image: 5 MB

Known limit: replacing media does not yet garbage-collect old files after settings update.
